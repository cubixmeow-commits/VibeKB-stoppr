Decisions

  • Imperative navigation instead of GoRouter

  • Environment-driven API configuration

    Verified from source

    API keys and Firebase config load from .env at runtime via EnvConfig; not bundled as assets.

    Application startup

  • Mobile-only platform support

    Verified from source

    firebase_options.dart throws for web, macOS, Windows, and Linux targets.

    Application startup
